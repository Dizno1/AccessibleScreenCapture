Configuration

Configuration sections are expanded on first launch. Collapse any section you do not need; AccessibleScreenCapture Pro remembers your choices for future launches.

  • Alt+Ctrl+Space takes a screenshot. Alt+Ctrl+R starts or stops recording. Alt+Ctrl+P pauses or resumes recording.
  • Alt+Ctrl+D turns the Capture Context Descriptor on or off. Alt+Ctrl+X checks capture readiness.
  • Global shortcuts work anywhere in Windows. The same actions are available from the application controls.
  • Captures wait in Review Queue until you save or discard them. You can keep capturing while items wait.
  • For screenshots, Confirm Capture privately identifies the captured window and content.
  • Import Video for Editing adds an existing video to Review Queue using a protected working copy. The original file is never changed.
  • For recordings, Review Recording moves focus to Play. Editing Instructions is immediately before Play.
  • Editing never changes the original recording. Open Editing Instructions for the editing keys.

Recording status feedback

Controls only recording started, paused, resumed, and stopped. Choose Spoken status, Status sounds, or Silence. This does not affect the screenshot sound, errors, or other important messages.

An independent, on-demand mode - not tied to taking a screenshot or recording. The Capture Context Descriptor announces the active application, window title, window state, monitor, and approximate screen coverage whenever they meaningfully change. It does not identify the focused control inside an application or webpage - that remains your screen reader's job. Off by default; stays on until you turn it off or exit the application.

Real testing found that using native speech was followed by JAWS losing speech and needing a restart. The exact cause hasn't been confirmed yet, so speech defaults off until repeated testing confirms it's safe. Turn it on to help test it; turn it off immediately if JAWS stops responding, and restart JAWS.

Enables native spoken announcements while another application has focus - the reliable spoken channel, independent of Windows notifications.

Displays a Windows toast notification independently of speech. A toast is a visual channel and is not guaranteed to be read by a screen reader - it supplements speech, it doesn't substitute for it.
