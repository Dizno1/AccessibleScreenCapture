AccessibleScreenCapture

Take screenshots and record your screen using only the keyboard.

An Open Door Design application.

  • Alt+Ctrl+Space takes a screenshot.
  • Alt+Ctrl+R starts or stops a recording.
  • Alt+Ctrl+P pauses or resumes an active recording.
  • Alt+Ctrl+D turns the Capture Context Descriptor on or off.
  • Alt+Ctrl+X checks capture readiness.
  • These shortcuts work anywhere in Windows, not only while AccessibleScreenCapture has focus. Ordinary application controls are also available for the same actions.
  • After a screenshot or recording, the result is available in Review Capture - Save Capture keeps it, Discard Capture removes it without saving.
  • Recording Options determine whether system audio and microphone audio are included in a recording.
  • Recording status feedback in Recording Options controls whether recording started, paused, resumed, and stopped are spoken, played as a sound, or silent.
  • Keyboard shortcuts can be customized further down the page, in Keyboard Shortcuts.

    Capture Context Descriptor

    An independent, on-demand mode - not tied to taking a screenshot or recording. The Capture Context Descriptor announces the active application, window title, window state, monitor, and approximate screen coverage whenever they meaningfully change. It does not identify the focused control inside an application or webpage - that remains your screen reader's job. Off by default; stays on until you turn it off or exit the application.

    Output Settings

    Real testing found that using native speech was followed by JAWS losing speech and needing a restart. The exact cause hasn't been confirmed yet, so speech defaults off until repeated testing confirms it's safe. Turn it on to help test it; turn it off immediately if JAWS stops responding, and restart JAWS.
