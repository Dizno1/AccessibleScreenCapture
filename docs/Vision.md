# Vision

AccessibleScreenCapture is a Screen Reader First application for taking
screenshots and recording the screen on Windows using only the
keyboard.

## Problem Statement

Windows does not currently provide a practical, screen-reader-accessible
workflow for taking screenshots or creating screen recordings.
AccessibleScreenCapture solves that problem.

## Who it's for

The application is for the general public, and should be equally usable
by screen reader users, keyboard users, educators, accessibility
professionals, developers, trainers, students, and content creators.

## Design Principles

Every feature must satisfy these principles:

- Screen Reader First
- Keyboard First
- Local First
- Browser Standards First
- Simple Before Powerful
- No Mouse Required
- No Drag-Based Workflows
- Clear Status Messages
- Professional Reliability

Accessibility is not an added feature. Accessibility is the
architecture.

## Phase 1 Scope

Phase 1 performs exactly two primary tasks:

1. **Screenshot** — take, save, choose save location, clear
   success/failure message.
2. **Screen Recording** — record with optional system audio and
   optional microphone audio, start, stop, save, clear success/failure
   message.

No editing, annotation, or cloud features are part of Phase 1.
